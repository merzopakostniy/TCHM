Политика конфиденциальности ТЧМ

Дата вступления в силу: 14 июня 2026 года

Настоящая политика описывает, какие данные обрабатывает мобильное приложение «ТЧМ» для iOS и Android, зачем они используются и как с нами связаться по вопросам конфиденциальности.

Какие данные обрабатываются

Приложение предназначено для внутреннего учета рабочих данных. В зависимости от заполнения пользователями оно может обрабатывать ФИО, табельный номер, класс, даты и служебные отметки, относящиеся к данным машинистов и колонн.

Для входа и синхронизации используются Firebase Authentication и Firebase Firestore. Приложение может создавать технический идентификатор пользователя Firebase и хранить роль пользователя, чтобы ограничивать доступ к просмотру или редактированию данных.

Для чего используются данные

  • для отображения и обновления данных колонн и машинистов;
  • для синхронизации данных между устройствами через Firebase;
  • для проверки роли пользователя и ограничения доступа к действиям;
  • для поддержания стабильной работы приложения.

Реклама и отслеживание

Приложение не показывает рекламу, не продает персональные данные и не использует данные для отслеживания пользователя в приложениях или на сайтах других компаний.

Передача третьим лицам

Данные хранятся и обрабатываются с использованием сервисов Google Firebase. Мы не передаем данные рекламным сетям или брокерам данных. Доступ к данным должен предоставляться только пользователям, которым он необходим для работы с приложением.

Хранение и удаление данных

Рабочие данные хранятся в Firebase Firestore до тех пор, пока они нужны для эксплуатации приложения. Запрос на исправление или удаление данных можно направить через контакт, указанный ниже.

Безопасность

Для защиты доступа используются правила Firebase Firestore и роли пользователей. При этом ни один способ передачи или хранения данных не может считаться абсолютно защищенным, поэтому доступ к приложению и учетным данным следует предоставлять только доверенным пользователям.

Дети

Приложение не предназначено для детей и не ориентировано на сбор данных детей.

Изменения политики

Мы можем обновлять эту политику при изменении функций приложения или требований законодательства. Новая версия публикуется на этой странице.

Контакты

По вопросам конфиденциальности откройте обращение в репозитории проекта: github.com/merzopakostniy/TCHM/issues.
