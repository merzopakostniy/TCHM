# Ключи регистрации руководителей

Ключ вводится при регистрации после выбора депо и открывает роль ТЧМ в этом
депо. Один ключ — одно депо: ключ ТЧ-16 к ТЧ-2 не подойдёт.

## Где что лежит

| Что | Где | Секретно |
|---|---|---|
| Сами ключи | `КЛЮЧИ_ДЕПО.txt` в корне, вне гита | **да** |
| Отпечатки и соль | `lib/invite_codes.dart` | нет |

В приложение попадают только отпечатки `sha256(соль + ключ)`. Восстановить по
ним ключ нельзя: в ключе 12 значащих знаков из алфавита в 30 символов — около
60 бит, перебор невозможен.

## Ограничение текущей схемы

Проверка идёт **на устройстве**, поэтому отозвать ключ можно только новой
сборкой. Это временно и снимается вместе с появлением сервера: тогда ключи
переезжают в таблицу `invites`, получают срок действия, лимит использований и
кнопку отзыва в кабинете руководителя, а `lib/invite_codes.dart` удаляется.

Пока сервера нет, действует правило: **ключ передаётся руководителю лично,
одним депо за раз**, а не общим списком в переписке.

## Как выпустить новый ключ

```bash
python3 - <<'PY'
import secrets, hashlib
ALPHABET = "23456789ABCDEFGHJKMNPQRSTVWXYZ"
SALT = "8b31db70913fe4fb62ec4bc89774d522"  # из lib/invite_codes.dart
NUMBER = 16                                 # номер депо

g = lambda n: "".join(secrets.choice(ALPHABET) for _ in range(n))
code = f"TCH{NUMBER:02d}-{g(4)}-{g(4)}-{g(4)}"
print("ключ:      ", code)
print("отпечаток: ", hashlib.sha256((SALT + code).encode()).hexdigest())
PY
```

Отпечаток заменить в `_fingerprints` в `lib/invite_codes.dart`, собрать и
раскатить сборку, ключ передать руководителю. Старый ключ перестанет работать
у тех, кто обновится.

## ТЧ-24 «Ильинское»

Новый ключ имеет префикс `TCH24` и формат 5-4-4-4. В справочнике и
отпечатках сохранён прежний внутренний id `novorizhskoe`, чтобы существующие
профили и данные оставались привязаны к тому же депо.

## Варшавское: СТЛ и БЛ

ТЧ-8 разделено на два независимых штата:

- `tch08` — «Варшавское — СТЛ», Серпуховско-Тимирязевская линия.
  Существующие профили, сотрудники, колонны и ключ сохранены.
- `tch08_bl` — «Варшавское — БЛ», Бутовская линия. Отдельный штат и ключ.

Оба ключа имеют префикс `TCH08`, но разные случайные части. Ключ одного
штата не подходит другому. Полные ключи находятся в `КЛЮЧИ_ДЕПО.txt`.
При сборке с `YANDEX_API=true` ключ проверяется сервером Yandex Cloud;
локальные отпечатки используются в остальных режимах приложения.
Автоматического переноса сотрудников из СТЛ в БЛ нет: для него нужен
согласованный список сотрудников и колонн.
