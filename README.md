# ТЧМ

Мобильное приложение Flutter для iOS и Android. В приложении 12 колонн, общий
просмотр данных машинистов, роли пользователей и синхронизация через Firebase
Firestore.

## Что уже есть

- вход как гость или как ТЧМ по общему паролю доступа;
- демо-режим без Firebase для проверки интерфейса;
- 12 колонн сразу после входа;
- у каждой колонны указан свой ТЧМ из списка;
- гость после пароля может только просматривать данные;
- ТЧМ после пароля и ввода табельного номера может менять все данные;
- поля из Excel: ФИО, класс, начало работы, талон, КИП, ТРА, АТЗ, сцеп, В/Н;
- дополнительное поле `ТЧМ машиниста`;
- начальное заполнение Firestore из демо-данных по колоннам 3 и 6.

## Быстрый запуск без Firebase

```bash
flutter run
```

На экране входа сначала выберите `Войти как инструктор` или `Войти как гость`.
Для гостя приложение попросит только пароль доступа `ТЧ-16`. Для инструктора
попросит табельный номер и пароль доступа `ТЧ-16`. В демо-режиме данные
хранятся только в памяти приложения.

## Подключение Firebase

1. Создайте проект в Firebase Console.
2. Включите Authentication -> Anonymous.
3. Создайте Firestore Database.
4. Добавьте iOS и Android приложения в Firebase.
5. Разверните правила из `firestore.rules`.
6. В Firebase Console откройте Authentication -> Get started -> Sign-in method
   и включите Anonymous.
7. Запускайте приложение обычной командой:

```bash
flutter run
```

Firebase-проект `tchm-9612d` уже прописан в `lib/firebase_options.dart`.
Для локального демо-режима без Firebase можно запустить:

```bash
flutter run --dart-define=FIREBASE_CONFIGURED=false
```

## Вход и права

Гость выбирает вход гостя, вводит пароль доступа, получает роль `viewer` и может
только просматривать данные.

Инструктор выбирает вход инструктора, вводит пароль доступа и табельный номер.
Приложение подставляет ФИО из локального справочника, а роль `tchm` выдается
только если пара
`табельный номер + ФИО` есть в allowlist внутри `firestore.rules`; после этого
можно добавлять, редактировать и удалять машинистов во всех колоннах.

## Firestore коллекции

- `columns` - 12 колонн;
- `machinists` - карточки машинистов;
- `users` - профили и роли пользователей.

Если Firestore еще пустой, приложение все равно сразу показывает 12 колонн из
локального справочника. При входе ТЧМ эти колонны автоматически синхронизируются
в Firestore. Стартовые записи машинистов из Excel можно добавить отдельным
начальным заполнением при необходимости.
