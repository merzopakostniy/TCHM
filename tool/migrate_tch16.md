# Миграция ТЧ-16 на вход по почте

Скрипт делает две вещи, обе безопасные — только дописывает поля, ничего не
удаляет:

1. проставляет `depotId: tch16` всем существующим профилям, колоннам и
   машинистам;
2. собирает реестр сотрудников `roster` из текущих профилей и из ТЧМ,
   указанных в колоннах, — чтобы при регистрации по почте роли и привязка
   инструкторов к колоннам не потерялись.

## Как запустить

Нужен ключ сервисного аккаунта из Firebase Console → Настройки проекта →
Сервисные аккаунты → «Создать закрытый ключ». Файл не класть в репозиторий.

```bash
cd tool
npm init -y && npm install firebase-admin
GOOGLE_APPLICATION_CREDENTIALS=./serviceAccount.json node migrate_tch16.js
```

Сначала прогнать вхолостую и посмотреть, что скрипт собирается записать:

```bash
GOOGLE_APPLICATION_CREDENTIALS=./serviceAccount.json node migrate_tch16.js --dry-run
```

## После миграции

Проверить в консоли выборочно: у профилей появился `depotId`, в `roster`
столько записей, сколько людей реально работает в приложении. Роли в реестре
можно поправить руками — оттуда их и возьмёт регистрация.
